# 计分板装备 / 海克斯识别：进展记录

分支：`feature/hex-scoreboard`（基于 `feature/platform-arch`，与 `feature/ai-advisor` 互相独立）。

## 已完成（可复现、有测试）

- **计分板布局标定**（`lolhex/vision/scoreboard.py`）：两队各 5 行、每行 7 格（6 件装备 + 1 个饰品），格子起点、间距、大小按 2880×5120 窗口像素标定。换分辨率或界面缩放需要重新标定。
- **装备识别**：图标库来自 `lolhex/data/item_icons.json`（装备），过滤掉 550xxx 段的界面素材（生命条色块、派对礼品）。
  - 占用判断：只看格子上半部分，跳过右下角的金币/数量数字。
  - 匹配：颜色 NCC，最佳分数低于 `MIN_SCORE = 0.55` 就报未知。
- **药水格**：库里的「生命药水」(2003) 是红色杯子，和游戏里的红药瓶不一致。用计分板上确认过的药水格做替换模板 `lolhex/data/item_2003_scoreboard.png`。留一法：三格互测，分别 0.92 / 0.996 / 0.996，都正确；扫描 140 个占用格，只命中药水。
- **误报修正**：英雄头像遮住的格子会报出错误装备（分数约 0.54）。阈值 0.55 挡掉了它。
- **准确率（挑选过的标注，仅作参考）**：三张截图共 29 格，答出 28 格，答出的全部正确。这不是完整标注，覆盖率没有测。

## 关于计分板海克斯图标（已确认的事实）

- 增强型海克斯（如「威能之追求」）在面板上显示的是**被增强的技能图标**（穿刺之箭），不是海克斯本身。之前我误以为是它自己的图标。
- 普通海克斯（如「神射法师」）的面板图标和 CDragon 小图（`cherry-augments.json` 的 `augmentSmallIconPath`，编号 129）是同一套设计（剑 + 放射纹路），颜色是反的（面板是褐色、暗背景）。
- 但用灰度/边缘/多尺度/SIFT 等方法做全库匹配，「神射法师」只能排到几十名，区分度不够。
- 公开图标库里很多图标都有相似的剑或放射纹路，单靠形状无法唯一确定。

## 实测经验（写给以后的自己）

- **点击要用 Retina 换算**：`CGEvent` 用的是点，窗口像素要除以缩放（`screen_pt`）。之前所有点击都发到了屏幕外。
- **辅助功能权限**：合成鼠标事件需要「辅助功能」授权，否则系统直接丢弃。
- **右键移动才算活动**：左键点击、原地右键都不能阻止「长时间休止」断线；真右键走到地面才有效。
- **悬停会弹浮窗挡住计分板**：鼠标不能停在计分板上。
- **误点会进入随机排队**：自定义建房页的「确认」按钮位置要用 OCR 核对，不要盲点。
- **断线弹窗**：先激活 Parallels，再点 OK，否则点击不生效。
- **macOS 系统弹窗**（如「允许配件连接」）会挡住界面，需要人来点。
